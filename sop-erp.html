SOP 2: Central Server, ERP & Database Maintenance

Target Scope: Enterprise Core Systems & Central Datacenter Operations

1. Specific Purpose & Objective

Governs scheduled operating system patching, database indexing, daily data backups, and capacity monitoring for the centralized Enterprise Resource Planning (ERP) platform.

2. Operational Importance

Guarantees data integrity for high-volume sales transactions, finance records, and nationwide supplier orders. Unplanned server outages halt orders across all branches; structured maintenance prevents corruption and maintains operational stability.

3. Maintenance Window & Workflow

  1. Scheduled Maintenance Window: Executed strictly during off-peak hours (Sundays between 01:00 AM – 04:00 AM SAST).
  2. Database Index Optimization: Database Administrators (DBAs) must run automated index defragmentation and query performance tuning weekly.
  3. OS & ERP Patching: Systems Administrators execute pre-tested vendor patch sets after obtaining formal Tier 3 Change Control authorization.

4. Backup & Capacity Requirements

  • Full Backup Schedule: Daily full backups at 23:00 SAST with transactional log backups every 15 minutes.
  • Encryption & Storage: Backup archives are encrypted with AES-256 and replicated offsite to secondary disaster recovery storage.
  • Storage Monitoring: Capacity alerts trigger automatically when server storage exceeds 80% utilization.
